## What changed since 0.5.0

- A Store screen: skills, MCP servers, models and Arcs in one place, and skills can be switched on and off there.
- An Arcs tab, hub shelves for cybersecurity and Arcs, and switches for desktop control and the web.
- The engine is one button: the app downloads llama.cpp for you, also during first-run setup on Linux.
- Home tells you what to do next, with starter prompts that fit the loaded model.
- The Agent view shows every agent session on this computer.
- Agent approvals show the whole command or diff on the card, with allow, deny, skip, edit, and allow for a whole kind.
- A first-run wizard, and tooltips for the jargon.
- Chat keeps streaming when you switch views, and replies render once per frame instead of per token.
- Chat code blocks pair up correctly: one-line fences, longer fences and closers with trailing text.
- Chat hides Retry until there is an answer to redo.
- Stop, cancel and launch no longer race each other in the engine and in jobs.
- The sessions list no longer shows "Invalid Date" for a session saved without a date.
- Harnesses open in a terminal that exists on Linux.
- Linux: ARM64 builds (AppImage and .deb), an Arch package that installs, and SHA256SUMS for every installer.
- Security: stricter checks on file paths from the window, safer harness launch, and only web links open outside the app.
- The panda comes to the desktop app, and speaks only when it has something to add.
- Flow opens centred; 3D edits stay off until there is a model.
- Small labels are a size larger and easier to read; keyboard focus and disabled states are clearer.
- The MIT licence ships inside the app.
- From now on a new version is published as soon as it is ready, so the app's update check finds it.
